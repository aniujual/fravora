Last updated: June 24, 2026 · Based on current app implementation

01

Quick Start

Go from install to your first running slideshow in five steps:

1
Open Fravora and complete onboarding. You can replay it anytime from Settings → Support → Replay Onboarding.
2
Go to Settings → Sources and add at least one photo source — local folder, SMB/NAS share, Google Photos, Microsoft OneDrive, Dropbox, or Immich.
3
Go to Settings → Albums, create an album, and attach the source folders or collections you added.
4
In Settings → Slideshow, set your preferred photo interval, display mode, and optional running hours.
5
Return to the frame view. The slideshow starts automatically once images are found.
💡
If nothing appears, check the in-app guidance cards — they explain missing albums, empty sources, or sources that haven't been scanned yet.

Sources

Sources define where your photos come from. Fravora supports local folders, network shares, and cloud services. Start by adding sources, then attach them to albums.

Network Shares (SMB / NAS)

Connect to any SMB-compatible NAS or shared folder on your local network.

Host / ShareEnter in hostname/sharename format — no smb:// prefix needed.
Test ConnectionVerify host/share path and credentials before saving to catch access issues early.
CredentialsUsername and password are optional — leave blank for guest access. Domain-qualified users are supported.
FoldersAfter connecting, choose one or more folders from the share. A share with no selected folders stays inactive.
Network Retry CountHow many times Fravora retries a failed image load before marking it unavailable. Increase for unstable networks.

Local Folders

Add folders stored directly on the device using Android's system file picker. You will be prompted to grant folder access.

External storage such as SD cards and USB drives is supported through Android's storage access framework.

✦
PRO: Albums can reference multiple local folders. Free tier is limited to one local folder per album.

Cloud Sources

Fravora supports cloud providers through a unified source flow. Supported cloud sources are Google Photos, Microsoft OneDrive, Dropbox, and Immich.

☁️
Cloud providers
Connect Google Photos, OneDrive, Dropbox, or Immich and choose the media items, folders, or albums you want to include in playback.
🧩
Unified limits
Free tier includes one cloud connection with base limits. PRO expands cloud limits across all supported cloud providers.
🔐
Cloud account management lets you switch or re-link services without rebuilding albums. Free tier supports one cloud connection; PRO expands cloud limits.

Cache & Storage

Image Cache SizeControls how much local storage is used for the resized image cache. Range: 128 MB to 2 GB with automatic pruning of older entries.
Low Storage AlertFravora warns you if your configured cache target exceeds currently available device storage.
Scan IntervalHow often Fravora rescans all enabled sources for new or removed photos. Range: 5 to 120 minutes.PRO
Google Photos headroomReserves free-space on your device before downloading Google Photos images, protecting against storage exhaustion. Includes status feedback and warning icons when your target exceeds available space.
Clear CacheAvailable for both standard image cache and Google Photos cache. Useful if old picks are no longer needed or the cache grows too large.

Albums

Albums are the playback collections Fravora scans for slideshow images. You can create multiple albums and turn each one on or off independently.

Create albumGive the album a name, then attach SMB folders, local folders, and/or cloud collections to it.
Enable for playbackOnly enabled albums are included in the slideshow. Toggle albums on/off without deleting them.
Include subfoldersRecursively scan nested folders within the attached source. PRO tier only.
Image countersEach album shows visible / hidden / total image counts so you can verify the configuration.
Hidden photosHide individual photos per-album or globally without deleting them. Unhide anytime from Settings → Albums → Hidden photos.
Hidden managerBrowse hidden photos as thumbnails, select multiple items, and unhide selected photos or unhide all at once.
⚠️
If all photos in your enabled albums are hidden, Fravora will show nothing. Go to Hidden photos to unhide some images.
💡
When importing from Google Photos, Fravora warns you if any selected picks are already hidden and excludes them automatically.

Voice Control

✦
PRO feature. Voice control requires microphone permission and an Android speech recognition service (typically Speech Services by Google).

Setup

1
Make sure Speech Services by Google (or another speech recognition service) is installed and set as the device voice input in Android Settings → General Management → Language and Input.
2
In Fravora, go to Settings → Voice and grant microphone permission when prompted.
3
Enable the Voice Control master toggle and review the activation disclaimer. First-time enable includes a mandatory 3-second acknowledgement lock.
4
Choose your wake phrase, optional wake feedback sound, and the feature toggles you want (radio, slideshow, assistant). Say the wake phrase and you will see a blue listening frame.
🛡️
Safety check (first enable): Voice Control shows a mandatory disclaimer with a brief acknowledgement lock before activation.

Wake Phrases

Hello FrameDefault wake phrase. Processed entirely on-device using OpenWakeWord.
Hello FravoraAlternative wake phrase. Same on-device processing.

Command Categories

Radio play commandsExamples: play/start/turn on/switch on/resume/unpause/begin/launch/enable/activate/open/run radio.
Radio stop commandsExamples: stop/pause/turn off/switch off/end/close/disable/deactivate radio.
Slideshow commandsExamples: play/start/turn on/resume slideshow and pause/stop/turn off/end slideshow.
Assistant volume commandsExamples: increase volume, decrease volume, set volume to 40, mute, and unmute.
Disable voice controlExamples: stop/disable/turn off/switch off/end/close/deactivate voice control (also works with voice shorthand).

Command Behavior

Wait for follow-upKeeps listening briefly after a command so you can issue another one without saying the wake phrase again.
Command windowAdjust how long Fravora listens for a command (3 to 7 seconds).
Runtime feature gatingRadio, slideshow, and assistant commands only run when their corresponding Voice settings toggles are enabled.

Parsing Rules

English-onlyVoice commands are currently parsed in English.
Noun-qualifiedCommands should include the target, for example play radio rather than only play.
Fuzzy matchingWake phrases tolerate slight variations, and command parsing accepts common filler words like stop the radio.
State-aware alternativesWhen speech alternatives conflict (for example start vs stop), Fravora chooses based on the current runtime state.

Visual Feedback

Blue frameFravora is listening for a command.
Green frame + soundCommand was recognized and acted on.
Red frame + soundSpeech recognition is unavailable or failed.
💡
If no station is configured and you say "play radio", Fravora opens Settings → Radio automatically so you can pick one.

FAQ & Troubleshooting

What is the fastest way to set up Fravora?
  • Add at least one source in Settings → Sources.
  • Create an album in Settings → Albums and attach source folders.
  • Enable the album for playback.
  • Set photo interval and display mode in Settings → Slideshow.
How do I use hidden frame features like zoom, panning, and quick radio controls?
In frame view, these shortcuts work as "hidden" interactions:
  • Double tap to zoom, pinch to zoom smoothly, and drag to pan while zoomed.
  • Ambient logo: single tap toggles radio play/pause, and double tap opens station search.
  • Weather overlay: tap to open detailed weather forecast (24-hour and 7-day views, PRO).
  • Clock/date overlay: tap to open the full-screen calendar (PRO).
  • New images badge: tap to open the new-images viewer when fresh photos are detected.
No photos are showing
  • Confirm at least one album exists and is enabled for playback.
  • Check that the album has at least one source folder attached.
  • If photos are in nested folders, enable Include subfolders (PRO for SMB).
  • Wait for the initial scan to complete — large folders take a moment.
All photos are hidden / slideshow is blank
Go to Settings → Albums → Hidden photos and unhide the images you want to show. Album counters display visible/hidden/total counts to help identify the issue.
SMB / NAS share won't connect
  • Verify the host/share path — use hostname/sharename format with no smb:// prefix.
  • Check your credentials. Try guest access (blank username/password) if the share allows it.
  • Increase Network Retry Count in Sources for unstable network links.
  • Ensure the device is on the same local network as the NAS.
Google Photos import is blocked or storage keeps filling up
  • Free up storage space on the device.
  • Increase Google Photos headroom in Sources to reserve more free space.
  • Clear the Google Photos cache from Sources settings if old picks are stale.
  • Watch cloud status icons in the frame notification strip: red means blocked, yellow means partial recovery, green means fully recovered.
Radio station won't play
Fravora shows the specific failure reason: timeout, network issue, access denied, unavailable stream, or unsupported format. Try a different station if the stream is down, or check your internet connection.
Why do some stations show warning icons in Radio settings?
Those are session-only station failure indicators. They mark stations that failed during the current app run so you can avoid unstable streams quickly.
Voice control won't enable or hears only one command
  • Install Speech Services by Google from the Play Store if it's not already present.
  • Set it as the default voice input: Android Settings → General Management → Language and Input → Voice Input.
  • Grant microphone permission to Fravora when prompted.
  • On first enable, complete the mandatory activation disclaimer acknowledgement.
  • Enable Wait for follow-up in Voice settings if you want multi-step voice interactions.
  • Increase the Command window timeout if commands are timing out too quickly.
How do I keep radio playing when the screen is off?
Enable Background playback in radio settings (PRO), then use lockscreen or notification controls to manage playback without reopening the app.
Can I run slideshow and radio on different schedules?
Yes. Slideshow running hours and radio running hours are separate, so you can keep background audio active on a different timetable than image playback.
Screen keeps turning off during slideshow
Enable Keep Screen Awake in Settings → Appearance. Also check your device's display timeout setting — some Android versions override app-level wake locks at aggressive timeout values.
PRO features disappeared after an ad session expired
Temporary PRO access from rewarded ads expires after the granted time (+15 min per ad, up to 4/day). Your PRO settings are saved and will be automatically restored the next time you activate PRO — either via another ad or a permanent purchase.
