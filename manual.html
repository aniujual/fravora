📖 Documentation

User Manual

Everything you need to set up, personalize, and get the most out of Fravora, from first launch to advanced gestures, overlays, audio, and voice workflows.

🚀 Quick Start

Go from install to your first running slideshow in five first-launch onboarding steps:

  • Open Fravora and complete first-launch onboarding. You can replay it anytime from Settings → Support → Replay Onboarding.
  • During onboarding, choose at least one photo source: local folder, SMB/NAS share, Google Photos picked photos, Microsoft OneDrive, Dropbox, or Immich.
  • Finish onboarding album setup by creating your first album and attaching your selected folders or cloud collections.
  • In Settings → Slideshow, set your preferred interval, display mode, and optional running hours.
  • Return to the frame view. The slideshow starts automatically once images are found.

If nothing appears, check the in-app guidance cards. They explain missing albums, empty sources, or sources that have not been scanned yet.

🗂️ Sources

Sources define where your photos come from. Fravora supports local folders, network shares, and cloud services. Add your sources first, then attach them to albums.

Network Shares (SMB / NAS)

  • Host/share format is hostname/sharename (no smb:// prefix required).
  • Test connection checks host/share path and credentials before saving.
  • Username and password are optional, including guest access and domain-qualified users.
  • After connecting, select one or more folders from the share to activate it.
  • Network Retry Count controls how many times Fravora retries failed image loads before marking them unavailable.

Local Folders

Add folders from internal storage, SD card, or USB media using Android's system picker. On Android TV devices without SAF support, Fravora uses a custom MediaStore-based folder picker instead.

PRO: Albums can reference multiple local folders. Free tier is limited to one local folder per album.

Cloud Sources

Supported cloud providers are Google Photos, Microsoft OneDrive, Dropbox, and Immich. The source flow is unified, so setup is consistent across providers.

  • Google Photos uses the official Picker flow with hand-selected picks, append support, and clear-picks actions per connection.
  • Free tier includes one cloud connection with base limits.
  • PRO expands cloud limits across all supported providers.
  • You can re-link or switch cloud accounts without rebuilding all albums.

Cache & Storage

  • Image Cache Size: 128 MB to 2 GB with automatic pruning.
  • Low Storage Alert: warns when configured cache exceeds available storage.
  • Scan Interval (PRO): 5 to 120 minutes for periodic source refreshes.
  • Google Photos headroom: reserves device free-space before downloading cloud items and shows a warning if the target exceeds available space.
  • Clear Cache: available for image cache and Google Photos cache.

🖼️ Albums

Albums are the playback collections Fravora scans for slideshow images. You can create multiple albums and enable or disable each one independently.

  • Create album: name it, then attach SMB folders, local folders, and/or cloud collections.
  • Enable for playback: only enabled albums are included in slideshow rotation.
  • Include subfolders: recursive folder scanning for deeper imports (PRO).
  • Image counters: each album shows visible, hidden, total, and pending Google Photos download counts.
  • Hidden photos: hide photos globally or per album and restore them later from Settings → Albums → Hidden photos.

If all photos in enabled albums are hidden, Fravora shows a blank slideshow until some images are unhidden.

▶️ Slideshow

Playback settings

  • Photo Interval: 10 to 600 seconds.
  • Instant Startup: last-session and random startup can show a cached photo immediately while scans complete in the background.
  • Pause/Resume Semantics: overlays, dialogs, and settings pause the timer without resetting the remaining time.
  • Image Order: Date Uploaded, Date Taken, Album Order, File Name, Random, or Smart Shuffle (PRO).
  • Smart Shuffle (PRO): reduces back-to-back similar shots by recognizing burst-like file/time patterns.
  • Display Mode: Fit (no crop) or Fill (edge crop).
  • Image Backdrop Style (PRO): styles empty letterbox areas in Fit mode.
  • Transition Effects: Free is hard cut only; PRO adds multiple animated transitions and transition speed control.
  • Cinematic Effects (PRO): Ken Burns, Drift, Vignette Pulse, and other motion presets.

Running hours & standby

  • Daily running window with start/end times.
  • Custom day-by-day schedule support.
  • Standby style outside running hours: digital clock, black screen, or bouncing clock (PRO).
  • Bouncing standby clock and overlay micro-shifts help reduce OLED burn-in risk.

If an SMB share goes offline, Fravora keeps the slideshow running from available images and shows a non-blocking warning when at least one image remains available.

🎨 Appearance

  • App Theme: Light, Dark, or System.
  • Color Schemes (PRO): seven curated themes with previews.
  • App Language: follow system language or force a selected language.
  • App Font Size (PRO): Small, Medium, Large, or Extra Large.
  • Fullscreen Mode: hides system bars for a true frame look.
  • Keep Screen Awake: prevents sleep while Fravora is foregrounded.
  • Premium Dashboard UI: card-based settings layout with unified iconography and themed tinting.
  • TV Compatibility: supports Android/Google TV and Amazon Fire TV launchers.

✨ Overlays

Overlays are information layers shown on top of photos during playback. Each one can be enabled, sized, and positioned independently.

  • Clock: configurable time/date display with trial timer toggle.
  • Weather: live local weather overlay with forecast details (PRO).
  • Photo metadata: taken date, location, and landmarks from EXIF (PRO).
  • Now Playing: scrolling station/song info while audio is active (PRO).
  • Ambient logo: pulsing Fravora icon and quick audio control target (PRO).
  • Photo index: current position indicator, such as 42 / 500 (PRO).
  • Speech recognition text: real-time on-screen feedback for voice commands.
  • Anti burn-in: micro-shifts overlays and adjusts opacity over time (PRO).

Overlay Layout (PRO): assign weather, clock, metadata, and logo to a 2x2 corner grid with collision-safe placement. Now Playing and Photo Index can use center slots.

🎵 Audio

Audio has two tabs: Radio for internet streams and Music for local playlists. Both share running-hours scheduling, background playback options, and media controls.

Radio (Free + PRO)

  • Search by station name with free search limits, or use advanced filters in PRO.
  • Play, pause, edit, and delete are available for the current station.
  • PRO unlocks favorites, recently played history, auto-add prompts, and auto-play options.
  • PRO enables background playback and lockscreen/notification media controls.
  • Fravora marks failed stations in-session so unstable streams are easy to avoid.

Music playlists (Free + PRO)

  • Free supports one playlist; PRO supports unlimited playlists.
  • Add whole folders recursively or individual files (MP3, M4A, AAC, FLAC, OGG, OPUS, WAV, AMR).
  • Manual refresh reports Added/Removed/Re-linked tracks.
  • Free keeps deduplication always on; PRO can disable deduplication.
  • PRO adds automatic background scanning with configurable intervals and expanded sort modes.

If a station fails, Fravora surfaces the reason directly: timeout, network issue, access denied, unavailable stream, or unsupported format.

🎙️ Voice Control

PRO feature. Voice control requires microphone permission and an Android speech recognition service (typically Speech Services by Google).

Setup

  • Install and set Speech Services by Google (or another voice service) as default voice input.
  • Grant microphone permission in Settings → Voice.
  • Enable Voice Control and complete the first-time safety disclaimer acknowledgement.
  • Choose wake phrase and optional feedback sound, then enable command categories you want.

Command behavior

  • Wake phrases: Hello Frame and Hello Fravora.
  • Supports slideshow, radio/music, volume, and disable-voice commands.
  • Wait for follow-up keeps listening briefly for multi-step interactions.
  • Command window is adjustable (3 to 7 seconds).
  • Runtime feature gating executes commands only when corresponding Voice toggles are enabled.
  • Video audio can pause or duck automatically while listening and resume after recognition.

Visual feedback: blue frame means listening, green means command accepted, red means recognition unavailable/failed.

🖐️ Frame Interactions

Fravora includes touch and overlay interactions that are faster than opening settings for frequent actions.

Slideshow gestures

  • Single tap opens the in-frame menu (when not zoomed).
  • Double tap toggles 2x zoom around the tap point, then resets.
  • Pinch-to-zoom and one-finger pan work for detailed inspection.
  • Swipe left/right navigates photos; swipe is locked while zoomed to avoid accidental skips.

Overlay interactions & status

  • Ambient logo single tap toggles audio play/pause; double tap opens station search.
  • Weather overlay opens detailed forecast views.
  • Clock/date overlay opens full-screen calendar (PRO).
  • Zoom navigator mini-map appears while zoomed.
  • Badges indicate network outages, app updates, Google Photos storage state, and newly discovered images.

🌦️ Weather Forecast

PRO feature. Tap the weather overlay in frame view to open full-screen forecast details.

  • 24-hour hourly strip plus 7-day daily forecast cards.
  • Swipe navigation inside hour/day detail views.
  • Forecast colors adapt to app theme and weather context.
  • Slideshow timer pauses while forecast is open and resumes after close.

📅 Calendar

PRO feature. Tap the clock/date overlay in frame view to open the full-screen calendar.

Views & events

  • Month swipe navigation and day-detail browsing.
  • Configurable week start for month grid layout.
  • Create, edit, and delete events with all-day support.
  • Recurring events with edit scopes and skip-date exclusions.
  • Per-event reminders: digest, 1-hour, and 15-minute options.
  • Reminder actions include Snooze, Dismiss, Delete, and Close.
  • Long-press day multi-select with bulk delete for faster cleanup.

⭐ Free vs PRO

The free tier is fully usable for daily photo frame operation. PRO removes limits and unlocks advanced capabilities with a one-time purchase (no subscription).

Free includes

  • Uninterrupted slideshow, scheduling, and core album/source baseline setup.
  • Local folders, NAS/SMB support, and one cloud connection baseline.
  • Clock overlay, hidden-photo controls, and core radio playback/search.

PRO unlocks

  • Expanded source/album/cloud limits and recursive include-subfolders.
  • Smart Shuffle, transition effects, transition speed, cinematic effects, and backdrop styles.
  • Weather/metadata/now-playing/ambient overlays plus anti burn-in.
  • Background audio, favorites/history, advanced station filters, and unlimited music playlists.
  • Voice control, calendar, color schemes, font sizing, and advanced UI controls.

Temporary PRO can also be enabled via rewarded ads. When temporary PRO expires, PRO preferences are preserved and restored automatically on reactivation.

🔧 FAQ & Troubleshooting

What is the fastest way to set up Fravora?
Complete first-launch onboarding, confirm your album is enabled, and set interval/display mode in Settings → Slideshow.
No photos are showing
Ensure an enabled album exists, at least one folder/source is attached, and initial scanning has completed.
All photos are hidden / slideshow is blank
Open Settings → Albums → Hidden photos and unhide selected items. Use visible/hidden/total counters to verify recovery.
SMB / NAS share will not connect
Use hostname/sharename, verify credentials, test connection, increase retry count for unstable links, and confirm local network reachability.
Google Photos import is blocked or storage keeps filling up
Free up storage, increase Google Photos headroom, clear stale cloud cache, and watch status icons for blocked, partial-recovery, and full-recovery states.
Voice control is not enabling reliably
Install Speech Services by Google, set it as default voice input, grant microphone permission, complete disclaimer acknowledgement, and increase the command window if needed.
Screen turns off during slideshow
Enable Keep Screen Awake in Appearance and review device-level display timeout/battery optimizations.
