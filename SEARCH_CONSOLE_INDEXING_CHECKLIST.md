# Search Console Indexing Checklist

Use this checklist right after deploying the new SEO pages.

## 1) Confirm sitemap is reachable
- Open https://aniujual.github.io/fravora/sitemap.xml in browser.
- Verify all new URLs are present and return HTTP 200.

## 2) Submit sitemap in Google Search Console
- Go to Indexing > Sitemaps.
- Submit: https://aniujual.github.io/fravora/sitemap.xml
- Wait for processing status to complete.

## 3) Request indexing for priority URLs
Priority order:
1. https://aniujual.github.io/fravora/
2. https://aniujual.github.io/fravora/features.html
3. https://aniujual.github.io/fravora/how-it-works.html
4. https://aniujual.github.io/fravora/download.html
5. https://aniujual.github.io/fravora/blog/index.html
6. https://aniujual.github.io/fravora/blog/reuse-old-android-tablet.html
7. https://aniujual.github.io/fravora/blog/smart-photo-frame-at-home.html
8. https://aniujual.github.io/fravora/blog/photo-frame-apps-compared-2026.html

## 4) Validate enhancements
- Use URL Inspection for each priority URL.
- Confirm detected rich results (FAQ / Breadcrumb / Article where applicable).
- If not detected immediately, run Rich Results Test and re-check after recrawl.

## 5) Monitor first 14 days
- Check Performance > Search results every 2-3 days.
- Filter by pages above and watch:
  - Impressions trend
  - CTR changes
  - New long-tail queries
- Expand FAQ and headings based on real query language.

## 6) Keep freshness signals updated
- Update sitemap lastmod when a page changes.
- Add one new informational blog post weekly for long-tail growth.
