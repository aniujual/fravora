Download Fravora and start your photo frame setup

Fravora is available on Google Play for Android tablets and display devices. You can start with local folders and expand to NAS/SMB or cloud sources later.

Compatibility overview

Fravora is built for Android devices used as dedicated displays. It works especially well on tablets, docked devices, and wall-mounted screens.

  • Android tablet and display device support
  • Local, NAS/SMB, and supported cloud sources
  • Offline slideshow support with local and NAS paths

Before you install

For the best experience, keep your device plugged in, disable aggressive battery optimization for long sessions, and choose a stable mount or stand location.

Quick start after install

  • Add at least one photo source
  • Create or select an album for playback
  • Set slideshow interval and display mode
  • Optionally enable overlays and voice control
