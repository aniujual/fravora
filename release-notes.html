Release Notes

Recent Fravora updates, feature additions, and bug fixes, published from the app changelog so the website stays aligned with the real product.

Version 1.0.10

vc31

Features

  • Added a one-time 1-hour PRO trial for new users, automatically granted on first app launch.
  • Added a temporary PRO countdown timer that appears while trial or ad-rewarded PRO access is active.
  • Overhauled onboarding with guided source setup, album creation, and optional radio selection for a complete first-run setup.

Bug Fixes

  • Hardened Google Play purchase launch with lifecycle and debounce guards, preflight refresh, and one transient retry to reduce rare billing startup crashes.
  • Fixed notification-strip icons disappearing on PRO/free tier changes by preserving badge and warning state across tier-driven scope refreshes.

Version 1.0.9

vc30

Features

  • Added network-share reconnect retry interval options (1/5/10/15/30/60 minutes or Never) for unreachable selected SMB shares.
  • Improved outage behavior so slideshows keep running with currently displayable and cached photos during network-share outages.

Bug Fixes

  • Fixed stale unreachable-share warning icon state so it clears after reconnect scans confirm shares are reachable again.
  • Fixed outage recovery behavior so reconnect does not trigger false new-images alerts.

Version 1.0.8

vc29

Bug Fixes

  • Fixed slideshow gesture handling so post-swipe movement no longer triggers false single-tap menu opens that blocked expected swipe/zoom behavior.
  • Fixed free-tier transition enforcement so downgrades always use None (hard cut) and never keep slide animation from prior PRO settings.
  • Fixed None transition rendering to lock to the active pager page, preventing slide-like motion from leaking through in free tier.

Version 1.0.7

vc28

Features

  • Added Image backdrop style option None so Fit mode can leave empty screen areas untouched with no backdrop fill.
  • Changed first-run defaults: slideshow running hours now start disabled, and free tier always uses Image backdrop None.
  • Added a one-time AI translation notice when switching to Local language for the first time; later Local-language switches apply directly.

Bug Fixes

  • Fixed production Support-screen crash from malformed positional format specifiers by hardening app-version and PRO label formatting arguments.
  • Fixed Transition effect None to perform hard cuts with no slide motion between photos.

Version 1.0.6

vc27

Bug Fixes

  • Fixed a Settings crash by loading Sources format-template strings with context resources instead of Compose stringResource empty-arg formatting.

Version 1.0.5

vc26

Features

  • Moved app update alerts to the in-frame strip with 24h periodic checks and a per-version acknowledgement guard to avoid repeated prompts.
  • Support now shows only the app version name in the App version row and no longer displays versionCode.
  • Added Immich cloud source with URL plus API key connection, album targets, scan integration, and runtime image loading and caching.
  • Switched Amazon flavor rewarded ads to APS and scoped AdMob SDK and manifest wiring to Google Play flavor only.

Bug Fixes

  • Fixed the Support update-check dialog text so it correctly says You are using the latest version of Fravora.
  • Fixed new images so they merge into the slideshow only after closing the preview; Random and Smart Shuffle append at the tail while other orders use their sort rule.
  • Fixed Amazon flavor update checks to skip Play in-app updates and route manual checks in Settings and the in-frame strip to Amazon Appstore.
  • Fixed Amazon store-launch errors by detecting missing Amazon Appstore app and showing a user message instead of crashing.
  • Fixed unreachable-share dialog actions by adding Retry now and changing the mislabeled cache-settings button text to Open Sources.

Version 1.0.3

vc24

Bug Fixes

  • Fixed permanent PRO purchase copy to use store-neutral billing wording so Amazon flavor no longer shows Google Play-specific messages.
  • Fixed TV monetization text to remove rewarded-ad references when ad-based temporary PRO is unavailable on Android TV, Google TV, and Fire TV.

Version 1.0.2

vc23

Features

  • Added Amazon Fire TV compatibility declaration for the Amazon flavor so the app can be listed for Fire TV devices.

Version 1.0.1

vc22

Features

  • Added Dropbox cloud integration with OAuth sign-in, folder targeting, slideshow scan and load support, and hidden-photo handling in Settings.
  • Added Android and Google TV support with leanback launcher, banner, and D-pad UX.
  • Added on-screen speech recognition text display during voice command listening with adaptive positioning and a user-configurable toggle in Settings.
  • Extended weather forecast hourly view from 12 hours to 24 hours for better future weather visibility.
  • Added a tap-open calendar overlay on the date and time widget with month swipe, configurable week start, and event add, edit, and delete support.
  • Added swipe navigation in weather detail views and a PRO-only Image backdrop setting in Slideshow.

Bug Fixes

  • Fixed metadata overlay duplication and related location and landmark normalization issues.
  • Fixed clear-image-cache behavior so closing Settings keeps the same slideshow photo instead of auto-advancing.
  • Fixed metadata sidecar staleness handling so cached metadata updates only when needed.

Version 1.0

vc21 to vc15 highlights

Highlights

  • Added slideshow zoom navigator, richer metadata overlays, weather forecast overlay, direct manual links, and remembered Settings scroll position.
  • Added Google Photos and OneDrive cloud sources, hidden photo controls, album image details, and improved folder picking.
  • Added encrypted SMB credential storage, anti-tamper enforcement, non-blocking radio failure indicators, and better crash diagnostics.
  • Added Keep Screen Awake, radio background playback, lockscreen controls, unified notification strip, and automatic update checks.

Bug Fixes

  • Fixed hidden overlay positioning, SMB outage fallback issues, payment outcome handling, language picker detection, and station warning dismissal behavior.
  • Fixed low-storage slideshow stalls and false unreachable-share warnings during cache-write blocks.
  • Fixed Now Playing positioning issues and aligned notification-strip behavior with in-frame overlays.
