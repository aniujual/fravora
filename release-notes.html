Release Notes

Recent updates, feature additions, and bug fixes published from the app changelog.

Version 1.1.2

vc10048

Features

  • Added video support (MOV, MP4, MKV) — albums can now include videos alongside photos.
  • Added per-album video controls: toggle video inclusion, set maximum duration and file size limits, and choose audio policy (Mute, Duck, or Play) for background music scenarios.
  • Overhauled music playlist system with folder-based playlists, re-linking, and tree-view library inspection.
  • Added high-performance music library syncing directly from SMB/NAS network shares.
  • Redesigned Settings as a Premium Dashboard with modern card-based layout.
  • Unified Audio section with dedicated Radio and Music tabs and per-tab state memory.
  • Added modern Android media controls with a system notification bar card for background playback and media resumption.
  • Integrated video playback with voice control — video audio pauses automatically during wake-word listening windows.
  • Added real-time progress indicators in Album and Source settings during active background media discovery.
  • Added usage summaries to storage source cards showing dependent Album and Playlist counts.
  • Added Right-to-Enter D-pad support for settings rows so DPAD Right opens actions.
  • Onboarding now probes sources and albums for actual media before enabling Next, with a spinner during probing and album editing in step 2.

Bug Fixes

  • Fixed TV local-folder add flow to avoid SAF dead-ends by using a custom picker first on TV with resilient fallback handling on non-TV.
  • Fixed MediaStore image folder discovery on some TV builds by adding a Files.Media fallback when image bucket metadata is missing.
  • Fixed in-frame menu Escape/Back handling to avoid app exit.
  • Fixed slideshow keyboard navigation on TV and emulator.

Version 1.1.1

vc10044

Features

  • Added hardware-aware gating for missing microphones or GPS.
  • Migrated Albums, Sources, and Calendar data to a Room database, replacing legacy storage for better performance and reliability.
  • Enhanced accessibility with descriptive TalkBack labels and optimized touch targets (48dp+) for main navigation elements.

Bug Fixes

  • Restored support for devices without microphones or GPS (such as many Android TV boxes) by marking those hardware features as not required.
  • Fixed Android TV launcher icon and banner quality issues by deploying high-resolution assets and implementing TV-specific resource overrides.

Version 1.1.0

vc10040

Features

  • Added PRO-only Cinematic Effect in Slideshow: Ken Burns pan-and-zoom animation synchronized with the global pause/resume state.
  • Added PRO-only Cinematic Speed control (Fast, Normal, Slow).
  • Enhanced Android TV experience with optimized D-pad navigation, clear visual focus indicators, and intelligent auto-focus during onboarding.
  • Refined overlay default sizes for new installations: clock (small), weather (medium), photo info (large), artist info (large).

Bug Fixes

  • Updated Google Play Billing Library to version 9.1.0 and hardened the purchase launch flow.
  • Fixed SMB folder picker to verify credentials before opening, preventing invalid root-folder additions.
  • Fixed a visual defect in the free-tier None transition where images were partially clipped during manual swipes.
  • Redesigned Android TV banner and icon as high-quality vector resources to meet Google Play quality guidelines.
  • Resolved an Android TV interaction issue where buttons occasionally required a double-press of the remote center button.

Version 1.0.10

vc31

Features

  • Added a one-time 1-hour PRO trial for new users, automatically granted on first app launch.
  • Added a temporary PRO countdown timer that appears while trial or ad-rewarded PRO access is active.
  • Overhauled onboarding with guided source setup, album creation, and optional radio selection for a complete first-run setup.

Bug Fixes

  • Hardened Google Play purchase launch with lifecycle and debounce guards, preflight refresh, and one transient retry to reduce rare billing startup crashes.
  • Fixed notification-strip icons disappearing on PRO/free tier changes by preserving badge and warning state across tier-driven scope refreshes.

Version 1.0.9

vc30

Features

  • Added network-share reconnect retry interval options (1/5/10/15/30/60 minutes or Never) for unreachable selected SMB shares.
  • Improved outage behavior so slideshows keep running with currently displayable and cached photos during network-share outages.

Bug Fixes

  • Fixed stale unreachable-share warning icon state so it clears after reconnect scans confirm shares are reachable again.
  • Fixed outage recovery behavior so reconnect does not trigger false new-images alerts.

Version 1.0.8

vc29

Bug Fixes

  • Fixed slideshow gesture handling so post-swipe movement no longer triggers false single-tap menu opens that blocked expected swipe/zoom behavior.
  • Fixed free-tier transition enforcement so downgrades always use None (hard cut) and never keep slide animation from prior PRO settings.
  • Fixed None transition rendering to lock to the active pager page, preventing slide-like motion from leaking through in free tier.

Version 1.0.7

vc28

Features

  • Added Image backdrop style option None so Fit mode can leave empty screen areas untouched with no backdrop fill.
  • Changed first-run defaults: slideshow running hours now start disabled, and free tier always uses Image backdrop None.
  • Added a one-time AI translation notice when switching to Local language for the first time; later Local-language switches apply directly.

Bug Fixes

  • Fixed production Support-screen crash from malformed positional format specifiers by hardening app-version and PRO label formatting arguments.
  • Fixed Transition effect None to perform hard cuts with no slide motion between photos.

Version 1.0.5

vc26

Features

  • Moved app update alerts to the in-frame strip with 24h periodic checks and a per-version acknowledgement guard to avoid repeated prompts.
  • Support now shows only the app version name in the App version row and no longer displays versionCode.
  • Added Immich cloud source with URL plus API key connection, album targets, scan integration, and runtime image loading and caching.
  • Switched Amazon flavor rewarded ads to APS and scoped AdMob SDK and manifest wiring to Google Play flavor only.

Bug Fixes

  • Fixed the Support update-check dialog text so it correctly says You are using the latest version of Fravora.
  • Fixed new images so they merge into the slideshow only after closing the preview; Random and Smart Shuffle append at the tail while other orders use their sort rule.
  • Fixed Amazon flavor update checks to skip Play in-app updates and route manual checks in Settings and the in-frame strip to Amazon Appstore.
  • Fixed Amazon store-launch errors by detecting missing Amazon Appstore app and showing a user message instead of crashing.
  • Fixed unreachable-share dialog actions by adding Retry now and changing the mislabeled cache-settings button text to Open Sources.

Version 1.0.1

vc22

Features

  • Added Dropbox cloud integration with OAuth sign-in, folder targeting, slideshow scan and load support, and hidden-photo handling in Settings.
  • Added Android and Google TV support with leanback launcher, banner, and D-pad UX.
